---
title: Health check
description: node ace agora:doctor checks the resilience configuration (and every other installed Agora lib) for what breaks in production, from the terminal or in CI.
icon: Stethoscope
---

`node ace agora:doctor` checks every installed `@adonis-agora` lib; `node ace resilience:doctor` checks resilience only.

```bash
node ace agora:doctor                  # every lib
node ace resilience:doctor             # resilience only
node ace agora:doctor --deep           # also ask Redis / the database
node ace agora:doctor --json --strict  # in CI: one JSON object, fail on warnings too
node ace agora:doctor --no-boot        # the app does not boot: peer and version checks only
```

| Flag | |
| --- | --- |
| `--lib=resilience,durable` | only these libs |
| `--only=resilience.store` | one check |
| `--deep` | also checks that reach Redis, the database or the network |
| `--json` | one JSON object on stdout |
| `--strict` | warnings fail too |
| `--verbose` | show skipped checks |
| `--no-boot` | do not boot the app (for when booting is what fails) |

Exit code: `0` no error, `1` at least one error (or a warning with `--strict`), `2` the doctor could not run.

Add it to CI after the build:

```yaml title=".github/workflows/ci.yml"
- run: NODE_ENV=production node ace agora:doctor --json --strict
```

## Checks

| Id | What it checks | Status |
| --- | --- | --- |
| `resilience.peers` | `@adonisjs/core`, and Redis / Lucid when installed, are in the supported range | error |
| `resilience.agora-siblings` | every `@adonis-agora` lib is on the same release | warn |
| `resilience.store` | `default` names a configured store; in production, the default store is not the in-memory one | error / warn |
| `resilience.policies` | every named policy builds (a misspelled store name shows up here) | error |
| `resilience.limits-scope` | in production, bulkheads and rate limiters are not on the in-memory store (they would limit per process) | warn |
| `resilience.store-reachable` (`--deep`) | every configured store answers, tables included | error |
